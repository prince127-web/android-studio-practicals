# Practical 13: Animations (Fade, Rotate, Blink, Move)

**Aim:** Write an Android Program to Demonstrate Animations: Fade, Rotate, Blink, and Move.

**Platform:** Android (Java, XML)

## Files

- `app/src/main/java/com/example/calculator/MainActivity.java`
- `app/src/main/res/layout/activity_main.xml`

Copy the files into an Android Studio project at the same paths (match the package name shown in the folder path).

## Setup notes

- Package name is `com.example.calculator` (the project was reused); rename via *Refactor > Rename* if you like.
- Needs a drawable named `car` (`@drawable/car`) that is not in the repo.
