# Practical 23: Flutter: CRUD with sqflite

**Aim:** Write a Flutter Program to Perform CRUD Operations Using the sqflite Package.

**Platform:** Flutter (Dart)

## Files

- `lib/main.dart`

Replace `lib/main.dart` in a new Flutter project (`flutter create .`), then run `flutter run`.

## Setup notes

- Add to `pubspec.yaml`: `sqflite` and `path` (`flutter pub add sqflite path`).
