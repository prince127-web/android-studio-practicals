# Practical 24: Flutter: REST API

**Aim:** Write a Flutter Program Using REST API.

**Platform:** Flutter (Dart)

## Files

- `lib/main.dart`

Replace `lib/main.dart` in a new Flutter project (`flutter create .`), then run `flutter run`.

## Setup notes

- Add the `http` package (`flutter pub add http`) and the INTERNET permission in `android/app/src/main/AndroidManifest.xml`.
