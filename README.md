## How to use

**Android:** create an Empty Views Activity project with the package name shown in the practical's folder path, then copy the `app/src/main/...` files over the matching ones.

**Flutter:** run `flutter create practical_N`, replace `lib/main.dart`, add any packages listed in that practical's README, then `flutter run`.
